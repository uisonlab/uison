# uison

[English](../README.md) · **Русский**

Маленький быстрый UI-фреймворк без зависимостей: экран описывается деревом элементов (JSON или кодом), логика пишется на Rust, C или C++, а окно, отрисовку и ввод берёт на себя uison. Одна программа работает на macOS, Windows, Linux (Wayland и X11), iOS, Android и в браузере.

```text
экран (JSON, Rust DSL, виджеты C++, UISON_JSON в C)  +  данные  +  обработчики на вашем языке
        │  привязки, шаблоны, темы, раскладка (uison-ui)
        ▼
кадр примитивов: rect, line, circle, tri, text, image, clip, hit
        │  сравнение с прошлым кадром → перерисовать только изменившееся
        ▼
бэкенд системы: AppKit, Win32 + Direct2D, Wayland/X11 + Cairo, UIKit, Android Canvas, canvas 2D
```

## Выберите язык

| | экран | логика | серия уроков |
|---|---|---|---|
| **Rust** | DSL цепочкой методов или JSON-файл | замыкания у элементов, `#[derive(Data)]` | [docs/rust](rust/README.md) |
| **C** | JSON прямо в коде (`UISON_JSON`) или файл | функции; структуры ↔ данные таблицами полей | [docs/c](c/README.md) |
| **C++** | виджеты C++20, как во Flutter | лямбды у элементов; структуры ↔ данные без макросов | [docs/cpp](cpp/README.md) |

Каждая серия читается от начала до конца без двух других: урок 0 — подготовка системы (macOS, Linux, Windows), дальше — от окна с кнопкой до потоков и своего кадра. Уроки со звёздочкой — одна и та же программа в трёх языках, их снимки совпадают до пикселя.

Пишете на ассемблере? [Два урока на x86-64 (NASM) и AArch64](asm.md) вызывают тот же C API.

## Проверка без окна

Любую программу можно прогнать сценарием: `UISON_SCRIPT=scenario.json` выполняет нажатия, ввод и прокрутку по `key` элементов, `UISON_CAPTURE=folder` сохраняет снимки окна. Так проверяются все уроки (`tools/lessons.sh`), примеры и телефоны.
