# Раскладка

[English](../../screens/layout.md) · **Русский**

Раскладка устроена как во Flutter: **ограничения идут вниз, размеры — вверх, положение задаёт родитель**. Родитель говорит ребёнку, сколько места есть (наименьший и наибольший размер). Ребёнок выбирает свой размер в этих пределах, а родитель ставит его на место. Единица — точка (pt). На экранах с плотностью 2× это два пикселя, тонкие линии выравниваются по физическим пикселям.

## Размеры: `w`, `h`

| значение | что |
|---|---|
| не задано, `"hug"` | по содержимому (по умолчанию; `Input` — `"fill"`) |
| `120` | ровно 120 pt |
| `"fill"` | всё доступное место |
| `"50%"` | доля доступного места родителя |

`minW`, `maxW`, `minH`, `maxH` ограничивают любой вариант. `fill` не выходит за свой `maxW`: так делаются колонки «на всю ширину, но не шире 640».

## Отступы

- `padding` — внутри узла (у контейнеров: `Box`, `Row`, `Column`, `Stack`, `Wrap`, `Center`, `Align`, `Flow`).
- `margin` — снаружи, у любого узла.

Оба принимают число, `[vertical, horizontal]` или `[top, right, bottom, left]`.

## `Row` и `Column`

```js
{ Row: { gap: 8, main: "between", cross: "center", children: [ … ] } }
```

- `gap` — расстояние между детьми.
- `main` — распределение по главной оси (у `Row` — по горизонтали): `start`, `center`, `end`, `between`, `around`, `evenly`.
- `cross` — по поперечной: `start`, `center`, `end`, `stretch`.
- `flex: 1` у ребёнка — доля свободного места по главной оси (`flex: 2` — вдвое больше). `w: "fill"` у ребёнка `Row` — то же, что `flex: 1`.
- `Spacer` — пустое место с `flex: 1`: `[Text, Spacer, Button]` прижимает кнопку вправо.
- `cross: "stretch"` растягивает детей по поперечной оси. Явный размер ребёнка по этой оси тогда не действует (как во Flutter). Чтобы блок был нужной ширины внутри `Column { cross: stretch }`, его кладут в `Align`.
- `stackBelow: 600` у `Row` — если места меньше 600 pt, дети встают столбиком (раскладка для телефона).

## `Box`, `Center`, `Align`

```js
{ Box: { padding: 16, fill: "$theme.card", radius: 12, stroke: "$theme.border", width: 1, child: { … } } }
{ Center: { child: { Text: { text: "Centered" } } } }
{ Align: { align: "bottomRight", child: { Button: { text: "Next" } } } }
```

`Box` — один ребёнок, заливка, рамка, скругление, `clip` (обрезать по своим границам), `align` (где ребёнок внутри). Положения: `topLeft`, `top`, `topRight`, `left`, `center`, `right`, `bottomLeft`, `bottom`, `bottomRight`.

## `Stack`

```js
{ Stack: { children: [
  { Image: { src: "photo.jpg", w: 320, h: 200 } },
  { Badge: { text: "New", place: "topRight", margin: 8 } },
  { Box: { pos: [12, 160], child: { Text: { text: "Caption" } } } },
] } }
```

Дети лежат друг на друге, размер `Stack` — по самому крупному. У ребёнка `place` — выравнивание, `pos: [x, y]` — точное положение. `overlay: true` — поверх всего и без влияния на размер `Stack` (выпадающий список `Select`, всплывающие панели).

## `Wrap`

```js
{ Wrap: { gap: 8, runGap: 8, children: [ { Badge: { text: "rust" } }, { Badge: { text: "c++" } } ] } }
```

Дети идут строкой и переносятся на следующую, когда место кончается. `gap` — между детьми, `runGap` — между строками, `cross` — выравнивание внутри строки.

## Текст и `Flow`

`Text` переносит слова по ширине. `maxLines` обрезает с многоточием, `wrap: false` отключает перенос, `align` выравнивает строки, `lineHeight` задаёт интервал.

`Flow` — один абзац из нескольких кусков: дети-`Text` с разным оформлением переносятся через свои границы, как текст в браузере. Внутри можно сделать жирное слово или ссылку в середине строки:

```js
{ Flow: { children: [
  { Text: { text: "Click " } },
  { Link: { text: "here", href: "https://example.com" } },
  { Text: { text: " to open the help.", italic: true } },
] } }
```

## Прокрутка: `Scroll`

```js
{ Scroll: { child: { Column: { children: [ … ] } } } }
```

Вертикальная прокрутка колесом, трекпадом и пальцем (с инерцией и отскоком), с полосой прокрутки. Ребёнок не меньше видимой области. Узлы вне видимой части в кадр не попадают, поэтому длинная страница рисуется так же быстро, как короткая.

## Списки: `For` и `List`

- `For` повторяет шаблон для каждого элемента массива и раскрывает все элементы. Подходит для десятков строк.
- `List` — прокрутка с виртуализацией: раскрывает только видимые строки. Подходит для тысяч строк; `itemHeight` у строк одинаковый.

Подробно — в [bindings.md](bindings.md#списки-for-и-list).

## Безопасная зона и клавиатура (телефон)

По умолчанию корень экрана лежит внутри безопасной зоны: под вырезом камеры и над полосой «домой» ничего не прячется. Экран с `safeArea: false` учитывает зону сам через `@env.safe.top`… — например, так заливают фон под системными панелями. Когда открыта экранная клавиатура, её высота добавляется к нижней зоне, и раскладка сжимается над ней.
