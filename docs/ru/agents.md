# Режим агента

[English](../agents.md) · **Русский**

LLM-агент может работать с программой на uison без снимков экрана. Программа описывает свой экран по смыслу, а не пикселями: у каждого элемента есть роль, имя, состояние и `key`. Агент действует по этому описанию: нажать `compose`, ввести в «Email», выбрать «Germany». Каждое действие проходит тем же путём, что мышь и клавиатура человека, поэтому агент не нажмёт выключенную кнопку или кнопку под диалогом.

```text
$ printf '{"id":1,"query":"text"}\n' | todo --agent
{"uison":0,"agent":1,"title":"uison todo"}
{"seq":1,"text":"scroll #root offset=0 content=800
  heading \"Todos\"
  textfield #draft/1/0 value=\"\" placeholder=\"What needs to be done?\" on=[submit]
  button \"Add\" #root/0/0/0/1/1 disabled
  option \"All\" #root/0/0/0/2/0/all selected
  checkbox \"Buy bread\" #1/0 unchecked
  button \"trash\" #del-1
  …"}
```

Есть два входа, оба через stdin и stdout:

- `--agent` — JSON-строки, для скриптов и своих агентов.
- `--mcp` — сервер [MCP](https://modelcontextprotocol.io): программа становится набором инструментов для Claude Code и других клиентов MCP.

```sh
cargo build --release -p todo --features agent
claude mcp add todo -- "$PWD/target/release/todo" --mcp
```

## Как включить в программе

Режим агента живёт в отдельном крейте `uison-agent`. Программа без него не меняется: те же кадры, тот же размер. Примеры `todo`, `form2`, `gallery`, `studio` и `disk-usage` включают его фичей `agent`:

```toml
[dependencies]
uison-agent = { version = "0.1", optional = true }

[features]
agent = ["dep:uison-agent"]
```

```rust
fn main() {
    #[cfg(feature = "agent")]
    if let Some(run) = uison_agent::mode(&mut std::env::args_os().collect()) {
        run(app(), "My app"); // --agent или --mcp: без окна
    }
    uison::run(app(), "My app");
}
```

Режим работает с экранами (`Ui`). Программе, которая сама пишет кадр (`App`), нечего описать.

## Что видит агент

`Ui::semantics()` превращает экран в узлы. Агент получает их текстом: один узел на строку, вложенные — с отступом.

| роль | откуда берётся | состояние |
|---|---|---|
| `button` | обработчик щелчка, интерактивный компонент | `disabled`, `menu` (есть контекстное меню) |
| `checkbox` | `toggle` по данным | `checked` / `unchecked` |
| `option` | `select` (вкладки, переключатели, строки для выбора) | `selected` |
| `button` … `collapsed` | `toggle` по локальному состоянию (выпадающий список) | `expanded`, `value` (что в нём показано) |
| `slider` | `drag` | `value`, `min`, `max`, `step` |
| `textfield` | `Input` | `value`, `placeholder`, `focused`, `password` (точки) |
| `link` | `href` | `url` |
| `list` | `List` (только видимые строки) | `count`, `first`, `offset` |
| `scroll` | `Scroll` | `offset`, `content` |
| `dialog`, `menuitem` | модальное окно (`dismiss`), открытое контекстное меню | |
| `text`, `heading`, `image` | текст вне элементов управления, `Image` с `alt` | |

Элемент управления называется текстом внутри него. Если текста нет, имя берётся из `tooltip` или из `alt` иконки внутри: `Icon` передаёт туда своё имя, поэтому кнопка-иконка читается как `"trash"`. Текст рядом с флажком в строке или прямо над полем в столбце становится подписью этого элемента. Чтобы назвать элемент самому, задайте `alt` у любого узла:

```json
{ IconButton: { icon: "trash", alt: "Delete task", on: { click: "remove" } } }
```

Строка из одного текста склеивается в одну строку: `text "Anna · Report · 10:42"`. Всё, что вне видимой части прокрутки, не попадает в описание. Исключение — интерактивные узлы: они остаются в списке с пометкой `offscreen`.

## Действия

| JSON (`--agent`) | инструмент MCP | что происходит |
|---|---|---|
| `{"do":"click","key":"add"}`, `"name":"Add"`, `"clicks":2`, `"button":"right"` | `click` | нажатие и отпускание на узле; если нужно, сначала прокрутка к нему |
| `{"do":"type","key":…,"text":"Milk","submit":true}` | `type` | фокус, выделить всё, набор (`"append":true` — дописать), Enter |
| `{"do":"key","code":"cmd+z"}` | `press_key` | клавиша узлу в фокусе (`cmd` — это Ctrl на Windows и Linux) |
| `{"do":"hover","key":"star"}` | `hover` | курсор задерживается на узле: подсказка, обработчики `hover` |
| `{"do":"scroll","key":"inbox","to":120}`, `"by"`, `"edge"` | `scroll` | к строке списка, к ключу, на сколько-то точек, к краю |
| `{"do":"set","key":"volume","value":50}` | `set_value` | слайдер перетаскивается, флажок нажимается, в поле набирается текст |
| `{"do":"pick","key":"country","option":"Germany"}` | `choose` | открыть выпадающий список и выбрать вариант; вкладки и переключатели тоже |
| `{"do":"menu","key":"row-17","item":"Delete"}` | `context_menu` | правая кнопка, потом пункт по имени |
| `{"do":"wait","ms":3000,"until":{"name":"Done"}}` | `wait` | настоящее время для фоновой работы, пока не появится узел или `{"path","value"}` |
| `{"query":"data","path":"todos"}` | `read_data` | модель данных; большие части сокращаются |
| `{"action":"remove","key":"del-1"}` | `call_action` | обработчик напрямую, без проверок экрана |

Узел указывают через `key` (с `#` из снимка или без) или через `name` (можно с `role`). Побеждает лучшее совпадение: имя целиком, потом его начало, потом целое слово, потом часть слова. Если одинаково хорошо подходят несколько узлов, ошибка перечисляет их ключи.

Ошибки объясняют причину: `'sendBtn' is disabled`, `'inc' is covered by 'scrim'`, `no node 'tabs'; under it: tabs/all, tabs/done`, `nothing named 'Sing up'`.

Ответ на действие перечисляет только то, что изменилось с прошлого взгляда агента (`+` добавлено, `-` убрано, `~` изменилось). Если новое — большая часть экрана или агент ещё не смотрел, ответ — весь экран. Запросы программы к системе приходят уведомлениями: `{"host":"open","url":…}`, `{"host":"copy","text":…}` и `{"host":"pick_file","action":…}`. На последний агент отвечает сообщением `{"action":…,"key":"/путь"}`.

## Время

Время в режиме агента виртуальное. После действия программа сразу приходит в покой: анимации доигрывают, таймеры срабатывают, задержка подсказки проходит — до секунды виртуального времени. Между шагами агента программа стоит. Работа в других потоках (сканирование диска, загрузка) при этом идёт, и `wait` даёт ей настоящее время. Щелчки разнесены во времени, так что два щелчка подряд — это два щелчка, а не двойной.

## Ограничения

- `Canvas` рисует свою картинку, и агент видит только узел (`canvas #chart`), а не фигуры. В Disk Usage диаграмма повторяет список, так что ничего не скрыто.
- Роли выводятся из поведения. Компоненту, которого не знает библиотека, может понадобиться `alt`.
- Одна программа — один агент, и пока агент управляет программой, у неё нет окна.
