# Elements

**English** · [Русский](../ru/screens/elements.md)

Generated by `uison-gen --md` from the screen schema (`uison_ui::schema`) and the library `lib/*.json` — don't edit by hand:
`cargo run -p uison-gen -- --md -o docs/screens/elements.md`.

Properties are named as in JSON. In C++ (`uison_widgets.hpp`) and in the Rust DSL the names are the same in `snake_case`: `maxLines` → `max_lines`.
Any property can also be set directly: `.prop("maxLines", 2)` (C++ and Rust).

## Behaviors

On built-in nodes (`Box`, `Row`, `Column`, `Stack`, `Wrap`…): the library elements are built from them.

| property | C++ / Rust | description |
|---|---|---|
| `toggle` | `toggle` | a press toggles the bool at the path: "@form.agree" |
| `select` | `select` | a press writes the value: { path: "@tab", value: "inbox" } |
| `drag` | `drag` | dragging sets a number: { path: "@volume", min, max, step } |
| `interactive` | `interactive` | hover/pressed states for { state: … } selectors |
| `focusable` | `focusable` | receives keyboard focus (Tab) |
| `dismiss` | `dismiss` | a press outside the node writes false to the path (closes a popup) |
| `href` | `href` | link: a press opens the address in the browser |
