# uison in C++

**English** · [Русский](../ru/cpp/README.md)

The screen is C++20 widgets, Flutter-style (`Column({.gap = 12, .children = {Text("…"), Button("+1", {.on_click = …})}})`), the logic is lambdas right on the elements, the data is your own structs; the window, drawing and input are uison's job. One program runs on macOS, Windows, Linux (Wayland and X11), iOS, Android and in the browser. You link a static or dynamic library and include the headers `uison.hpp` (C++17) and `uison_widgets.hpp` (C++20).

- **[Quick start](quickstart.md)** — your first program, built with a single command or with CMake.
- **[The screen language](../screens/README.md)** — the shared reference: bindings, layout, [elements](../screens/elements.md), themes.
- **[Phones](../mobile.md)** and **[the browser](../wasm.md)**.
- **API reference** — the comments in [`uison.hpp`](../../crates/uison-c/include/uison.hpp) and [`uison_widgets.hpp`](../../crates/uison-c/include/uison_widgets.hpp) (generated by `uison-gen`; IDE tooltips show the field descriptions).
- **Examples** — [`examples-cpp/`](../../examples-cpp): `todo-cpp`, `list10k-cpp`, `worker-cpp`, the `cpp-test` test; `cmake -S examples-cpp -B out/cpp/build && cmake --build out/cpp/build`.

## Lessons

Each lesson is a program in [`examples-cpp/lessons`](../../examples-cpp/lessons). `tools/lessons.sh cpp` builds them all, runs the scenarios and updates the screenshots. Lessons marked with a star are the same program as in the [Rust](../rust/README.md) and [C](../c/README.md) series: the screenshots of all three languages match pixel-for-pixel (`tools/lessons-compare.sh`).
