uison browser

A tiny browser with no dependencies: HTML and CSS are read by its own parsers and turned into uison screen JSON — the same JSON people write by hand for apps.

HTML→ DOM→ CSS cascade→ uison JSON→ frame of primitives

Switch the view to JSON at the top right to see what this page turned into: blocks became Column and Box, paragraphs became Flow of Text runs, links became text with a nav action.

Real websites

HTTPS goes through the system's own TLS (CoreFoundation on macOS and iOS, OpenSSL on Linux, WinHTTP on Windows): not a single dependency. External CSS isn't loaded yet, so sites look "unstyled", like in 1995. You can type an address yourself too.

  • info.cern.ch — the very first website (1991)
  • text.npr.org — NPR news as plain text
  • lite.cnn.com — the lightweight version of CNN
  • Hacker News — table-based layout
  • Wikipedia: World Wide Web — a big page
  • 68k.news — news in simple HTML for vintage computers
  • wiby.me — a search engine for the "old web"
