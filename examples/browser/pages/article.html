The World Wide Web (WWW, or simply the web) is a distributed system that gives access to linked documents stored on many different computers connected to the Internet. Besides the full name, people also use the word web and the abbreviation WWW.[1] The web is made up of hundreds of millions of web servers; most of its resources are hypertext, in which links lead to other documents.

Background

The idea of linked documents is older than computers. In 1945 Vannevar Bush described the "Memex", a machine in which a reader could connect microfilms with "trails" of association. In the 1960s Ted Nelson coined the word hypertext and started Project Xanadu, and Douglas Engelbart demonstrated the NLS system — with a mouse, windows and links between documents. That 1968 demonstration later became known as "the Mother of All Demos".

By the late 1980s the Internet already connected universities and laboratories, but documents lived on different machines in different formats. To find something you had to know where it was and be able to use a dozen programs: ftp, telnet, Gopher, WAIS.

"HyperText is a way to link and access information of various kinds as a web of nodes in which the user can browse at will."
— Tim Berners-Lee, "Information Management: A Proposal", 1989

The first browser and the first website

In March 1989 Tim Berners-Lee, who worked at CERN, wrote a memo about an information management system. His supervisor Mike Sendall wrote on the cover: "Vague but exciting". In 1990, together with Robert Cailliau, he revised the proposal, and by the end of the year the first web server and the first browser — which was also an editor — WorldWideWeb, were running on a NeXT computer.

The first website, info.cern.ch, described the project itself: what hypertext is, how to set up a server and how to write a browser. You can still open it today — including with this browser, over plain HTTP.

Few people ever saw the NeXT browser, so in 1991 a simple text browser, the Line Mode Browser, appeared; it ran on any terminal. It showed links as numbers in square brackets: to follow one, you typed its number.

Mosaic

The web became truly popular in 1993, when the National Center for Supercomputing Applications (NCSA) released Mosaic — a browser with images right in the text that ran on Windows, Macintosh and Unix. That same year CERN gave up its rights to the technology, and the web became a public good.

HTML, HTTP and URL

The web rests on three simple ideas. A URL is the address of any document; HTTP is the protocol a browser uses to request a document from a server; HTML is the markup language in which text is marked up with tags and links point to other URLs.

GET /hypertext/WWW/TheProject.html HTTP/1.1
Host: info.cern.ch
Connection: close

HTTP/1.1 200 OK
Content-Type: text/html

The first versions of HTML were tiny: headings, paragraphs, lists, links. Tables, forms and images were added gradually, and browsers forgave markup errors — an unclosed <p> closed itself before the next block. This tolerance became the norm and is written into the modern standard: HTML parsing is specified as an exact algorithm that knows what to do with any page, even a broken one.

Cascading Style Sheets

Early pages were styled right in the markup: <font color="red">, <center>, tables for column layout. In 1994 Håkon Wium Lie proposed CSS — Cascading Style Sheets, which separate presentation from content. The word "cascade" means that styles from different sources — the browser, the page author, the user — are layered by rules: importance, selector specificity, order.

The browser wars

In the second half of the 1990s Netscape Navigator and Internet Explorer competed by adding their own tags and features: <blink>, <marquee>, layers, different versions of JavaScript. Sites were made "best viewed in…", and developers had to maintain several versions of their pages. The answer was the W3C web standards and the movement to follow them.

The 2000s brought Firefox, Safari and Chrome; engines became open source and standards became shared. Today browsers update every few weeks, and a new CSS feature usually reaches all major browsers within a year or two.

The web today

A modern page is not just a document but also an application: JavaScript, networking, graphics, video. A browser engine is one of the most complex programs there is: millions of lines of code, its own programming language, its own graphics subsystem. That is why small browsers like this one show only the essence: parse HTML, apply CSS, lay out blocks and lines — and draw.
